🧩 Understand task → 🤔 Decide action → 🔧 Use tool → 📥 Process result → (repeat) → 💬 Respond

## 🛡️ Guardrails

- **Read-only SQL**, enforced twice: a code check (SELECT only, one statement) and SQLite `PRAGMA query_only`
- **Safe mode**: the data-changing tool is blocked unless the user switches it off
- **Safe calculator**: parses arithmetic only, so it can't run code
- **Step limit**: stops runaway loops and answers with partial results
- **Prompt-injection rule**: tool results are treated as data, not instructions (tested in notebook Part 6)
- **Errors go back to the agent** (bad SQL, unknown city, API down), so the app never crashes
- **Automatic model switching** when a free-tier daily limit is reached
